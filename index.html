AP SIO1

Projets réalisés en première année

Projet 1 : AP1-4-GSB-InfraVirtuelle

Semestre 1

Contexte : Dans le cadre de cet atelier professionnalisant, j'ai réalisé la conception et le déploiement de l'infrastructure réseau pour l'organisation GSB (Galaxy Swiss Bourdin). L'objectif principal était de mettre en place un environnement réseau complet et fonctionnel, allant de la modélisation théorique à la virtualisation réelle des systèmes. Ce projet s'est articulé autour de la simulation d'architectures sous Packet Tracer, de l'installation de postes clients sous Windows 11 et Ubuntu, ainsi que de la configuration de services d'infrastructure critiques tels que le DNS et le routage inter-réseaux.

Technologies : Cisco Packet Tracer, Oracle VM VirtualBox, Windows 11 Professionnel, Ubuntu 22.04 LTS, serveur DNS/Web, routage IP, adressage IPv4 statique, masques de sous-réseau, passerelles par défaut, réseaux internes virtuels, switchs virtuels, configuration réseau Netplan, configuration du BIOS, tests de connectivité (ping), résolution de noms (nslookup).

Productions :

  • AP1-4-GSB-InfraVirtuelle

Compétences mobilisées : B1.1 B1.5

Projet 2 : AP2-4 InfraDevWeb

Semestre 2

Contexte : Dans le cadre de cet atelier professionnalisant, j'ai réalisé le déploiement d'une infrastructure réseau multiservices pour les départements DIR, DSI et RH. Ce projet a consisté à importer et configurer des machines virtuelles Windows et Ubuntu via des fichiers OVA pour simuler l'environnement client. J'ai pris en charge l'administration complète d'un routeur, incluant la sécurisation des accès par console et SSH, ainsi que la configuration de services DHCP pour l'adressage dynamique du réseau. Technologies : Importation d'images OVA, Ubuntu Desktop 24, Windows 11, routeur Cisco, administration port console, SSH, protocole DHCP, adressage IP dynamique et statique, bornes Wi-Fi, configuration de SSID, chiffrement WEP (Static Web Key), logiciel de terminal Putty, segmentation VLAN, interfaces virtuelles, routage inter-VLAN (sub-interfaces), mode Trunk (802.1Q), interface GigabitEthernet

Projets réalisés en deuxième année

Projet 1 : EXAMEN MACHINE

Année SIO2

Contexte : Conception et mise en place d’une infrastructure réseau virtualisée et sécurisée, organisée autour de plusieurs VLANs afin de segmenter les différents usages (serveurs, DMZ, Wi-Fi, réseau informatique). Le projet intègre des services essentiels tels que le contrôleur de domaine, la supervision et la gestion d’inventaire situés dans une zone serveur interne. Des serveurs web et de bases de données sont disponibles depuis l’intérieur du réseau et l’extérieur, tout en assurant leur isolation via une zone DMZ. Une réplication des données a été mise en place entre les deux bases de données, garantissant la redondance, la continuité de service et la cohérence des informations. L’ensemble est interconnecté par un commutateur, un routeur et est protégé par un pare-feu, garantissant à la fois la sécurité, la performance et la bonne gestion des flux réseaux conformément au schéma proposé. Un réseau Wi-Fi visiteurs est configuré pour assurer aux clients de l’entreprise une connexion internet. Le VLAN Informatique assure la supervision globale de l’infrastructure et dispose d’un accès complet à l’ensemble des équipements d’interconnexion.

Technologies : Environnement virtuel VMware + Virtualbox Conteneurisation Docker Zone Serveurs, serveur AD/DNS (Windows Server 2022) Outil de supervision Zabbix Outil de gestion d’inventaire OCS/GLPI Zone Serveurs DMZ, serveur web Apache et base de données MariaDB Pare-feu Stormshield, commutateur Cisco, Routeur Cisco DHCP, VLANs, borne Wi-Fi Sniffeur réseau Wireshark, PC de test

Productions :

  • EXAMEN_MACHINE

Compétences mobilisées : B1.1 B1.4 B1.5 B1.6

Projet 2 : AP2-1 Déploiement site E-commerce Odoo

Année SIO2

Contexte : Dans le cadre de cet atelier professionnalisant, j'ai accompagné la société SynapsInfo dans la mise en œuvre d'un PGI (Progiciel de Gestion Intégré) open source pour répondre aux besoins de l'entreprise Spécibike. L'objectif principal était de déployer, configurer et tester la version communautaire d'Odoo sur un serveur Linux afin de centraliser la gestion des activités. Ce projet a impliqué l'installation technique du serveur et de sa base de données, l'importation massive du catalogue produits et des données clients depuis des fichiers Excel, ainsi que la personnalisation fonctionnelle de l'outil. J'ai notamment configuré les modules de comptabilité, d'inventaire et de vente en ligne pour aboutir à un site e-commerce opérationnel incluant un site vitrine et les mentions légales obligatoires.

Technologies : PGI Odoo 17 (version communautaire), Ubuntu 22.04 LTS , base de données PostgreSQL, pgAdmin4, WinSCP, serveur Web Apache2, tableur Microsoft Excel (XLSX/CSV), modules Odoo (Accounting, Inventory, Employees, Website), outils de gestion de stockage Linux (growpart, resize2fs), gestionnaire de services systemctl, mode développeur Odoo pour la modification des vues et modèles
